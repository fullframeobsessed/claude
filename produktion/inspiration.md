**Wichtigste Erkenntnis:** Unser Bild wechselt drei- bis zehnmal langsamer als in den Vorbildern. Das ist der größte Hebel für Spannung, noch vor der Stimme.

## 1. Livera: Motion Graphics als Showreel
- **Kinetische Typografie:** Wörter knallen formatfüllend ins Bild („CLAUDE“), Wortwände wiederholen sich („NEVER NEVER NEVER“).
- **Harte Farbflächen:** Rot, Schwarz, Creme, Kobaltblau, Neongelb. Jede Szene hat *eine* Farbe.
- **Easing:** Bewegungen federn nach (Bounce, Elastic) statt linear zu laufen. Das wirkt lebendig.
- **Formen verwandeln sich:** Kreis wird Dreieck wird Quadrat, gelegentlich ein 3D-Gitter.
- **HUD-Details:** feine Rahmen, Zeitcodes und Beschriftungen am Rand wirken „designt“.
- **Ende:** ein Logo-Reveal mit Untertitel.

## 2. Nectar: Launch-Video
- **Punch-Karten:** Ein Satz, weiß auf schwarz, formatfüllend („Until today.“). Das setzt dramatische Pausen.
- **Wortwände** mit dem Produktnamen im Hintergrund, Hauptbegriff groß davor.
- **Tipp-Animation:** Eine UI tippt live „Find me 40 moms“. Abstrakte Dinge werden so konkret.
- **Raster:** viele Gesichter oder Bilder im Grid zeigen „Masse“.
- **Archivbilder in Schwarz-Weiß** als ironischer Kontrast. Für uns nicht übertragbar (Rechte), aber das *Prinzip* Kontrast schon.
- **Kurze Untertitel** (3–5 Wörter) mitten im Bild statt langer Zeilen unten.

## 3. Zoro: Sprecher + Grafik
- **Wörter im Raum:** Schlüsselwörter erscheinen groß neben dem Sprecher, synchron zur Stimme („exactly“, „That changes today“).
- **UI-Karten** ploppen auf (Listings, Erinnerungen, Bewertungen) und machen das Produkt greifbar.
- **Große Zahlen** als Overlay („$25,000“).
- **Weiche Farbverläufe und leuchtende Kugeln** als Übergang zwischen Themen.

## Was wir für Otto übernehmen (Video 01, Version 3)
| Prinzip | Umsetzung bei Otto |
|---|---|
| **Neues Bild alle 2–4 s** | Pro Satz mindestens ein visueller Wechsel: Otto-Pose, Zoom auf Detail, Text-Einblendung |
| **Kinetische Typografie** | Schlüsselwörter (FAUL?, 95 %, JETZT) knallen synchron zur Stimme ins Bild |
| **Punch-Karten** | Kernsätze weiß auf Orange: „Du bist nicht faul.“ / „Otto flüchtet vor einem Gefühl.“ |
| **Federnde Animationen** | Otto, Requisiten und Karten ploppen mit Nachfedern rein |
| **Zahlen zählen hoch** | „95 %“ zählt von 0 hoch, die Personen im Raster färben sich nacheinander |
| **UI-Karten** | Handy-Benachrichtigungen („Neue Nachricht 🔔“) und eine Steuererklärung, die sich „tippt“ |
| **Wortwand** | „MORGEN MORGEN MORGEN …“ hinter Morgen-Otto |
| **Raster** | 20 Ottos, die alle gleichzeitig aufschieben (Kapitel 1) |
| **Untertitel** | Wort-für-Wort bleibt, zusätzlich Schlüsselwörter groß im Bild |
| **Musik + Sounds** | Swoosh bei Einblendungen, Plopp bei Pop-ins, Musikteppich |

**Bewusst nicht übernehmen:** fremde Logos, Archivfilme (Rechte), den Stil 1:1. Unser Look bleibt Creme, Orange und Otto.
